# Pixel Adventure Agrinho

Projeto de jogo em HTML5 / Construct 2 com estilo pixel art.

## Sobre

Este repositório contém os arquivos do jogo "Pixel Adventure Agrinho", incluindo o executável em HTML, scripts, recursos gráficos e áudio.

## Estrutura do projeto

- `index.html` - página principal do jogo.
- `c2runtime.js` - motor do Construct 2 para execução do jogo.
- `data.js` - dados do evento e objetos do jogo.
- `jquery-3.4.1.min.js` - biblioteca jQuery usada pelo projeto.
- `offline.js`, `offlineClient.js`, `sw.js` - arquivos de suporte para funcionamento offline.
- `appmanifest.json` - manifesto de aplicativo web progressivo (PWA).
- `images/` - pasta com imagens e sprites do jogo.
- `media/` - pasta com efeitos sonoros e música.

## Como executar

1. Abra `index.html` em um navegador compatível com HTML5.
2. Para melhor experiência, use um servidor local (não apenas abrir o arquivo diretamente) e acesse pelo navegador.

### Exemplo com Python

```bash
cd "c:\Users\Usuario\Documents\vscode\Pixel-Adventure-Agrinho"
python -m http.server 8000
```

Depois, abra `http://localhost:8000` no navegador.

## Observações

- O jogo foi criado no Construct 2 e exportado para a web.
- Caso queira editar o projeto diretamente no Construct 2, o arquivo `.capx` original pode estar disponível separadamente.
